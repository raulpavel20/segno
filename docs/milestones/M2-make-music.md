# M2: Make music

**Goal:** finish a track in the DAW with only our devices. That means:
- MIDI parts written in a piano roll;
- assistants able to drive the DAW and its devices through MCP;
- audio and MIDI recorded in;
- a mixer with sends and returns;
- automation;
- dynamics on tracks and the master;
- an exported file.

See [roadmap.md](../roadmap.md) and the device specs in `devices/*/SPEC.md`.

**Status:** ◐ in progress (started 2026-10-09). Everything built up to 2026-10-10 (A2–A5, B1–B3, C1–C4, C5a, C5b, C9) is signed off by the product owner, as is M1 (its framework freeze is [ADR 0034](../decisions/0034-device-api-frozen.md)). C7 (bounce, [design](../design/bounce.md)) built and signed off the same day. C6 (fades and crossfades, [design](../design/fades.md)) built and signed off the same day, with the review's fixes ([ADR 0037](../decisions/0037-a-pass-makes-its-own-clip.md): a pass makes its own clip; seams between clips). C5c (comping) built and signed off the same day, with its review ([ADR 0038](../decisions/0038-comping-you-can-listen-through.md): audition, sections). Next: C8 export, then B4 Spectrum.

## Order of work

0. **A3, the module panel kit** (product owner, 2026-10-09: before anything else, so every later module is built on it). Then **A4, the UI foundations**, before the mixer and automation build on the track headers and time views.
1. **C1, the command palette.** It is small, makes every action reachable, and is used daily from then on.
2. **C2, the piano roll.** Without it you can't write music in the DAW.
3. **C9, the MCP server.** Early, so that each later step adds its own tools as it lands (cheaper than retrofitting), and so that development gets a live way to inspect and drive the running app.
4. **A1, then B1 and B2 (Compressor, Gate), then A2 (sidechain), then B3 (Limiter).** One detector core, three devices.
5. **C3 the mixer, A5 selection and the context panels, and C4 automation.** The mixer gives the master track a place for the Limiter. A5 settles what the panels show in each view before automation lanes add another kind of selection.
6. **C5a recording and C5b takes, then C7 bounce** (C7a in place, then C7b to a new track). Built.
7. **C6 fades, then C5c comping (its joins are fades), C8 export, B4 Spectrum.**
