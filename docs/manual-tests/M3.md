# M3 manual checks

What the product owner checks by hand before signing off M3 ([plan](../milestones/M3-workflow-and-space.md)). Judge feel in a Release build.

## Presets (A1; signed off 2026-10-11)

- [ ] Every module's header shows ‹ the preset's name ⌄ › and an A button, right of the module's name; nothing touches, on the narrowest module (Utility) too
- [ ] A new module reads "Default settings"; move a knob: a dot follows the name; move it back (or undo): the dot goes
- [ ] Click the name: the list opens under it (or above, where there's no room below), the search field ready to type
- [ ] The arrow keys load each preset as they move, so you hear each one; Enter keeps the one you're on; Ctrl+Z after it undoes the whole browse in one step
- [ ] Escape closes the list and puts back what was there before it opened
- [ ] Typing filters by name, tags and description; the tag buttons and Favourites narrow the list; a star makes a preset a favourite, in the plugins too
- [ ] Save as…: the form opens in place with the name selected; a name you already use asks to Replace; the new preset shows in the list, and the module reads its name
- [ ] Right-click one of yours in the list: Rename… edits it in place; Delete moves it to the system's trash; Show in folder opens its folder
- [ ] The presets are files in Documents/Segno/Presets/<Module>; copy one in by hand: it shows the next time the list opens
- [ ] ‹ and › step through the presets (the list as last filtered), wrapping round
- [ ] A switches to B (one undo step): edit B, switch back to A and forth; Copy A to B (right-click the name, or Module) makes them the same; save, reopen: A and B are still there
- [ ] Use as the default for a new Compressor: the next Compressor added starts from it ("Default"); Clear the default: back to its own
- [ ] A parameter with automation keeps following its lane after a preset loads; the others take the preset's values
- [ ] The Module menu lists every preset command for the selected module; dimmed with no module selected
- [ ] In another DAW (REAPER, Bitwig, Ardour): the plugin's header has the same bar and list; its window grows while the list is open; a preset saved there shows in Segno, and the other way round; the host's program list shows Default settings and the factory presets
- [ ] Assistants: list_presets, load_preset, save_preset and compare do what the header does

## Settings (C1; for review)

- [ ] Options > Settings… (Ctrl+,) and the top bar's settings button show Settings in the centre; the browser and inspector stay, the detail panel hides; ✕, Escape, Settings… again or Mixer view close them, back to the view you came from
- [ ] The search narrows the page as you type, marks what matched, dims the sections left empty; "nothing like this" says No setting matches; Changed only shows only what you've changed
- [ ] Set up your interface from scratch: driver, output and input, channels, sample rate and buffer (each with its latency); Play the test tone; the Load line counts dropouts
- [ ] Change the buffer while a song plays: the audio stops for a moment and playing goes on
- [ ] Linux: with JACK or PipeWire's JACK running, JACK is in the driver list; a first launch (no Settings.xml in ~/.config/Segno) picks it
- [ ] Turn a MIDI input off: it's ignored everywhere; Computer keyboard on: Segno opens with it playing
- [ ] Recording: FLAC, 16-bit; record a pass: the file is a FLAC; Count-in follows the Record button's menu and the other way round; the Record button's menu "Recording settings…" opens the page at Recording
- [ ] Each choice marks its default ("(default)"); change one: the section's title row shows Reset; Reset puts the whole section back and hides itself
- [ ] Library: Move… the Segno folder elsewhere: your presets come along; New projects: Save as… starts there
- [ ] Plugins: Add… a folder with a plugin, Scan: it's found; a plugin that crashes a scan shows under Skipped with Try again
- [ ] Export: change the defaults; a new project's export panel starts from them; an export makes its settings the next new project's
- [ ] Keys: click a shortcut, press new keys: the menus, tooltips and palette show them at once; a key another action has asks "… is X's." with Replace and Cancel; Backspace clears one; Reset all shortcuts appears while any differs
- [ ] Interface size 125 %: everything grows at once; Automatic: back
- [ ] The command palette lists "Settings: Buffer size" and the rest; choosing one opens the page at its row, marked for a moment
- [ ] The Assistants popover's "All assistant settings…" opens the page at Assistants
- [ ] Quit and reopen: everything is as you left it (~/.config/Segno/settings.json; app.json and assistants.json are gone into it)
- [ ] Narrow window (compact width): nothing touches; long action names in Keys fit beside their shortcuts

## Factory presets (B11; signed off 2026-10-11, the Sampler's to come)

Listen through each set in the DAW (the arrow keys in the list load as they go). For each: does the name say what you hear, does it sound good, is anything missing or redundant? Say what to change; Claude changes it.

- [ ] Utility (5): Mono check, Invert polarity, Pad -6 dB, Wide, Remove DC
- [ ] Spectrum (6): Mixing, Flat, Mid and side check, Find resonances, Fast, Slow and smooth
- [ ] EQ (18), on a vocal, drums, bass, a guitar or keys, and a mix
- [ ] Compressor (15), on the same; Sidechain duck with a kick under Sidechain; De-ess on a vocal with Listen
- [ ] Gate (12), on drum microphones with bleed, a vocal, a guitar; Trance gate with a rhythmic sidechain
- [ ] Limiter (12), on a mix and on busses
- [ ] Saturator (15): each about as loud as the dry sound, so you hear the colour, not the level
- [ ] Subtractive Synth (35): basses low, leads and keys in the middle, pads with chords, drums around C1 to C3
