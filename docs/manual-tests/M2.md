# M2 manual checks

What the product owner checks by hand before signing off M2 ([plan](../milestones/M2-make-music.md)). Judge feel in a Release build.

## Command palette (C1)

- [ ] Ctrl+K opens the palette at the top; typing a few letters of any action finds it ("zo fit", "metro", "save")
- [ ] Arrows and Enter run the selected action; Escape or a click elsewhere closes it; shortcuts work again at once
- [ ] Actions you ran recently come first

## MIDI clips and piano roll (C2)

- [ ] Double-click an empty spot on a track: a one-bar MIDI clip appears from the grid line before it, the clip view opens, and a track without an instrument gets the Subtractive Synth
- [ ] Clicking a track header or empty space shows the devices again; clicking the MIDI clip shows its notes; Tab switches either way
- [ ] Double-click in the grid draws a note one grid step long and plays it; keep holding and drag right to lengthen it
- [ ] Moving a note feels direct: it snaps in time, plays each new pitch, and Alt moves it freely
- [ ] Resizing by either edge, box selection, Shift-click, and Ctrl+A / Ctrl+D / Delete on notes all behave as expected
- [ ] ↑ / ↓ (Shift for octaves) transpose, ← / → nudge, Ctrl+U quantises; each is one Ctrl+Z
- [ ] Velocity lane: drawing across stems sets them; dragging a selected stem moves the selection's velocities; quiet notes look fainter
- [ ] Clicking the keyboard plays the notes; dragging over it plays a glissando
- [ ] Wheel scrolls pitches, Shift+wheel time, Ctrl+wheel / pinch zooms, Alt+wheel row height; the grid gets finer as you zoom in
- [ ] The clip view's top edge resizes it; the size is kept with the project
- [ ] The edited clip plays back as drawn, in time with the arrangement and the metronome
- [ ] Drawing or dragging a note past the clip's end lengthens the clip to the end of that bar (one Ctrl+Z undoes both); with another clip right after it, the clip stays and the note shows faded

## Module panels (A3)

- [ ] Every module looks like one family: the same knob size, label and value spacing, section titles and lines; nothing feels hand-placed
- [ ] Utility no longer feels empty; the Synth and Sampler no longer feel cluttered; it's clear which controls belong together
- [ ] Clicking a section title collapses it to a strip and back; Alt+click collapses or expands all sections; the chain reflows at once
- [ ] The fold chevron folds a module to a strip; clicking the strip unfolds it; dragging the strip or the header background reorders; clicking header controls never drags
- [ ] Collapsed sections and folded modules come back after saving and reopening the project, and never appear in undo or mark the project unsaved
- [ ] A section's power toggle (Saturator Color, Sampler Filter, EQ band) dims just that section
- [ ] The bottom panel height (232 px modules) feels right on the laptop and on the 4K display
- [ ] Plugins: the editor resizes when a section collapses (Reaper, Bitwig, Ardour, Carla), and the collapsed state survives saving the host project
- [ ] The UI says "module" everywhere (tab, add button, tooltips, palette)

## UI foundations (A4)

- [ ] Nothing looks different from before, except: the piano roll's ruler matches the arrangement's; the transport bar's spacing follows one rhythm; the detail panel's Modules / Clip tabs can be clicked
- [ ] The arrangement and the piano roll feel the same: wheel, Shift+wheel, Ctrl+wheel, pinch, ruler drag and ruler click
- [ ] Hover and press states look the same on every button, toggle, combo and tab

## Compressor (B1)

- [ ] On drums, vocals and a bus, it sounds like a good compressor: Clean stays transparent at moderate settings; Glue holds a mix together without pumping
- [ ] The curve: dragging the point moves the threshold, dragging right of it changes the ratio, Shift is fine, double-click resets; the dot follows the level as audio plays
- [ ] The history scrolls smoothly and reads clearly: input, output and gain reduction, with the threshold line
- [ ] Turning knobs, switching Character, Detector, the sidechain filter, Auto Makeup, Auto Release and Listen while playing never clicks
- [ ] Lookahead: changing it in the DAW briefly restarts playback and the track stays in time with the others; in a plugin host (Reaper, Bitwig, Ardour) the host's delay compensation follows
- [ ] Listen with a high-pass at 200 Hz plays the drums without their low end; the compressor then ignores the kick
- [ ] Ratio at the top reads "∞:1", in the DAW and in a host's generic editor (CLAP and VST3)
- [ ] The meters and the reduction read the same as the sound suggests (at −20 dBFS in and the threshold at −30, 3:1 shows about 6.7 dB of reduction)

## Gate (B2)

- [ ] On a drum close mic, it removes the bleed between hits cleanly: hits keep their attack (try Lookahead 1 ms), tails close without chopping (Hold, Release)
- [ ] A slowly fading sound near the threshold opens once and closes once: no fluttering (Return)
- [ ] Range at -inf is silence; at -20 dB the closed sound is clearly quieter but still there
- [ ] Expander turns the noise floor down gradually; Ratio and Range do what they say
- [ ] Flip on a drum mic plays only the room between the hits
- [ ] The history: the level, the output and the open stretches read clearly; dragging the solid line moves the threshold and the dashed one the return
- [ ] Switching Mode, Flip, Listen and the sidechain filter while playing never clicks

## Limiter (B3)

- [ ] On a full mix, Gain up to +6 dB makes it louder without audible pumping or distortion; the history shows the reduction
- [ ] Standard: lowering the Ceiling limits harder. Maximise: lowering the Ceiling only turns the whole output down, the reduction stays the same
- [ ] With True Peak on, a mastering meter (or the readout) never shows more than the ceiling in dBTP
- [ ] M/S on a wide mix: the centre (vocal, kick) keeps its level while the sides give way
- [ ] Bass-heavy material limited by 6 dB stays clean (no buzzing on low notes)
- [ ] The readout: short-term and integrated LUFS match a reference meter within 0.5 LU on a song; Reset starts the integrated value again
- [ ] Changing Lookahead or True Peak while playing keeps the track in time (the DAW restarts playback; hosts follow the new latency)
- [ ] Switching Mode and Channels while playing never clicks

## Mixer in the arrangement (C3a, C3b)

- [ ] Two tracks playing: the meters in the headers move with the sound; muting one (M, or Alt+M) silences it and its meter
- [ ] Solo (S, or Alt+S) plays just that track and its reverb return; Ctrl+click solo adds a second track; Ctrl+Z never undoes a solo
- [ ] Volume and pan bars (make a track taller to see them) feel like the modules' bars: drag, Shift for fine, double-click resets, type "-6"
- [ ] Ctrl+Alt+T adds "A Return"; put a module on it; a track's send in the inspector (with Pre on or off) feeds it; the reverb follows the track's volume only when Pre is off
- [ ] The master row selects the master: its chain takes the Limiter; its volume turns the whole mix down
- [ ] Ctrl+Alt+R hides and shows the returns and the master
- [ ] A mix exported or rendered sounds like playback (the master is no longer 3 dB down)

## Mixer view (C3c)

- [ ] "Mix" in the transport bar (or Ctrl+Alt+X) shows every channel as a strip; "Arrange" goes back to the arrangement where it was
- [ ] Faders feel right: 0 dB sits at a comfortable height, Shift is fine, double-click returns to 0 dB, the value under the fader takes a typed "-6"
- [ ] The meters move with the sound; the peak readout holds the loudest peak and resets on a click; it turns red above 0 dBFS
- [ ] Clicking a strip selects the track (the inspector and the modules follow); clicking a module name opens that module below
- [ ] Modules, Sends and Narrow change every strip at once; with 30+ tracks, Narrow and horizontal scrolling keep it usable; the master stays in view
- [ ] The view and its options come back after saving and reopening the project

## Sidechain (A2)

- [ ] In the DAW, a Compressor on a bass with Sidechain set to the kick track ducks the bass on every kick; muting the kick track keeps the ducking (a "ghost" kick)
- [ ] The picker lists the other tracks by name and follows renames; a track that already listens to this one isn't offered
- [ ] Changing the source while playing restarts playback briefly and stays in time; Ctrl+Z puts the old source back
- [ ] A Gate keyed from a hi-hat track opens a pad in rhythm
- [ ] Plugins (Reaper, Bitwig, Ardour): route a track to the plugin's sidechain input and set the picker to External: it ducks; on Off it ignores the input; with External and nothing routed it behaves as without a sidechain (VST3); the choice survives saving the host project
- [ ] Ask the assistant to sidechain the bass compressor to the kick: it uses `set_module_sidechain`, and the picker shows the kick

## Assistants over MCP (C9)

- [ ] The spark button in the transport bar opens the Assistants popover; Escape or a click elsewhere closes it; it fits the shell's look
- [ ] Turning it on shows "Listening on 127.0.0.1:7377"; it's still on after restarting the DAW; off, nothing listens
- [ ] Claude Code: paste the copied `claude mcp add` line in a terminal; `/mcp` in Claude Code lists segno with its tools
- [ ] Claude Desktop (or another app that starts a process): the copied configuration works with the DAW running, and also with it closed (it then runs without a window and stops when the app does)
- [ ] Ask the assistant to build a short loop (a drum pattern, a bassline, a filter setting on the Synth): the tracks, clips and notes appear as it works, the light by the spark blinks, and it sounds right
- [ ] Every change it made is one Ctrl+Z, and the palette's undo says "Assistant: …"
- [ ] Ask it to render and check the loop: the numbers it reports make sense (peak, RMS, bands), and playback wasn't interrupted
- [ ] Ask it to collapse a section or fold a module: the panel follows at once, and it never appears in undo
- [ ] Read only: it can still read and render, but every edit is refused with a clear message
- [ ] With unsaved changes, ask it to start a new project: you're asked first (in the assistant's app, or by the assistant), and nothing is lost if you say no
- [ ] New token: the connected assistant stops working until the new line is pasted
