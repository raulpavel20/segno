# M2 manual checks

What the product owner checks by hand before signing off M2 ([plan](../milestones/M2-make-music.md)). Judge feel in a Release build.

## Command palette (C1)

- [ ] Ctrl+K opens the palette at the top; typing a few letters of any action finds it ("zo fit", "metro", "save")
- [ ] Arrows and Enter run the selected action; Escape or a click elsewhere closes it; shortcuts work again at once
- [ ] Actions you ran recently come first

## MIDI clips and piano roll (C2)

- [ ] Double-click an empty spot on a track: a one-bar MIDI clip appears from the grid line before it, the clip view opens, and a track without an instrument gets the Subtractive Synth
- [ ] Clicking a track header or empty space shows the devices again; clicking the MIDI clip shows its notes; Tab switches either way
- [ ] Double-click in the grid draws a note one grid step long and plays it; keep holding and drag right to lengthen it
- [ ] Moving a note feels direct: it snaps in time, plays each new pitch, and Alt moves it freely
- [ ] Resizing by either edge, box selection, Shift-click, and Ctrl+A / Ctrl+D / Delete on notes all behave as expected
- [ ] ↑ / ↓ (Shift for octaves) transpose, ← / → nudge, Ctrl+U quantises; each is one Ctrl+Z
- [ ] Velocity lane: drawing across stems sets them; dragging a selected stem moves the selection's velocities; quiet notes look fainter
- [ ] Clicking the keyboard plays the notes; dragging over it plays a glissando
- [ ] Wheel scrolls pitches, Shift+wheel time, Ctrl+wheel / pinch zooms, Alt+wheel row height; the grid gets finer as you zoom in
- [ ] The clip view's top edge resizes it; the size is kept with the project
- [ ] The edited clip plays back as drawn, in time with the arrangement and the metronome
