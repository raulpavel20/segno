# M2 manual checks

What the product owner checks by hand before signing off M2 ([plan](../milestones/M2-make-music.md)). Judge feel in a Release build.

**Signed off** by the product owner on 2026-10-10: every section written up to that date. Sections added later are checked before M2's own sign-off.

## Command palette (C1)

- [ ] Ctrl+K opens the palette at the top; typing a few letters of any action finds it ("zo fit", "metro", "save")
- [ ] Arrows and Enter run the selected action; Escape or a click elsewhere closes it; shortcuts work again at once
- [ ] Actions you ran recently come first

## MIDI clips and piano roll (C2)

- [ ] Double-click an empty spot on a track: a one-bar MIDI clip appears from the grid line before it and the clip view opens; a track without an instrument gets none (it says "No instrument")
- [ ] Clicking a track header (any track's, including the clip's own) or empty space shows the modules again; clicking the MIDI clip shows its notes; Tab switches either way
- [ ] Double-click in the grid draws a note one grid step long and plays it; keep holding and drag right to lengthen it
- [ ] Moving a note feels direct: it snaps in time, plays each new pitch, and Alt moves it freely
- [ ] Resizing by either edge, box selection, Shift-click, and Ctrl+A / Ctrl+D / Delete on notes all behave as expected
- [ ] ↑ / ↓ (Shift for octaves) transpose, ← / → nudge, Ctrl+U quantises; each is one Ctrl+Z
- [ ] Velocity lane: drawing across stems sets them; dragging a selected stem moves the selection's velocities; quiet notes look fainter
- [ ] Clicking the keyboard plays the notes; dragging over it plays a glissando
- [ ] Wheel scrolls pitches, Shift+wheel time, Ctrl+wheel / pinch zooms, Alt+wheel row height; the grid gets finer as you zoom in
- [ ] The clip view's top edge resizes it; the size is kept with the project
- [ ] The edited clip plays back as drawn, in time with the arrangement and the metronome
- [ ] Drawing or dragging a note past the clip's end lengthens the clip to the end of that bar (one Ctrl+Z undoes both); with another clip right after it, the clip stays and the note shows faded

## Module panels (A3)

- [ ] Every module looks like one family: the same knob size, label and value spacing, section titles and lines; nothing feels hand-placed
- [ ] Utility no longer feels empty; the Synth and Sampler no longer feel cluttered; it's clear which controls belong together
- [ ] Clicking a section title collapses it to a strip and back; Alt+click collapses or expands all sections; the chain reflows at once
- [ ] The fold chevron folds a module to a strip; clicking the strip unfolds it; dragging the strip or the header background reorders; clicking header controls never drags
- [ ] Collapsed sections and folded modules come back after saving and reopening the project, and never appear in undo or mark the project unsaved
- [ ] A section's power toggle (Saturator Color, Sampler Filter, EQ band) dims just that section
- [ ] The bottom panel height (232 px modules) feels right on the laptop and on the 4K display
- [ ] Plugins: the editor resizes when a section collapses (Reaper, Bitwig, Ardour, Carla), and the collapsed state survives saving the host project
- [ ] The UI says "module" everywhere (tab, add button, tooltips, palette)

## UI foundations (A4)

- [ ] Nothing looks different from before, except: the piano roll's ruler matches the arrangement's; the transport bar's spacing follows one rhythm; the detail panel's Modules / Clip tabs can be clicked
- [ ] The arrangement and the piano roll feel the same: wheel, Shift+wheel, Ctrl+wheel, pinch, ruler drag and ruler click
- [ ] Hover and press states look the same on every button, toggle, combo and tab

## Compressor (B1)

- [ ] On drums, vocals and a bus, it sounds like a good compressor: Clean stays transparent at moderate settings; Glue holds a mix together without pumping
- [ ] The curve: dragging the point moves the threshold, dragging right of it changes the ratio, Shift is fine, double-click resets; the dot follows the level as audio plays
- [ ] The history scrolls smoothly and reads clearly: input, output and gain reduction, with the threshold line
- [ ] Turning knobs, switching Character, Detector, the sidechain filter, Auto Makeup, Auto Release and Listen while playing never clicks
- [ ] Lookahead: changing it in the DAW briefly restarts playback and the track stays in time with the others; in a plugin host (Reaper, Bitwig, Ardour) the host's delay compensation follows
- [ ] Listen with a high-pass at 200 Hz plays the drums without their low end; the compressor then ignores the kick
- [ ] Ratio at the top reads "∞:1", in the DAW and in a host's generic editor (CLAP and VST3)
- [ ] The meters and the reduction read the same as the sound suggests (at −20 dBFS in and the threshold at −30, 3:1 shows about 6.7 dB of reduction)

## Gate (B2)

- [ ] On a drum close mic, it removes the bleed between hits cleanly: hits keep their attack (try Lookahead 1 ms), tails close without chopping (Hold, Release)
- [ ] A slowly fading sound near the threshold opens once and closes once: no fluttering (Return)
- [ ] Range at -inf is silence; at -20 dB the closed sound is clearly quieter but still there
- [ ] Expander turns the noise floor down gradually; Ratio and Range do what they say
- [ ] Flip on a drum mic plays only the room between the hits
- [ ] The history: the level, the output and the open stretches read clearly; dragging the solid line moves the threshold and the dashed one the return
- [ ] Switching Mode, Flip, Listen and the sidechain filter while playing never clicks

## Limiter (B3)

- [ ] On a full mix, Gain up to +6 dB makes it louder without audible pumping or distortion; the history shows the reduction
- [ ] Standard: lowering the Ceiling limits harder. Maximise: lowering the Ceiling only turns the whole output down, the reduction stays the same
- [ ] With True Peak on, a mastering meter (or the readout) never shows more than the ceiling in dBTP
- [ ] M/S on a wide mix: the centre (vocal, kick) keeps its level while the sides give way
- [ ] Bass-heavy material limited by 6 dB stays clean (no buzzing on low notes)
- [ ] The readout: short-term and integrated LUFS match a reference meter within 0.5 LU on a song; Reset starts the integrated value again
- [ ] Changing Lookahead or True Peak while playing keeps the track in time (the DAW restarts playback; hosts follow the new latency)
- [ ] Switching Mode and Channels while playing never clicks

## Mixer in the arrangement (C3a, C3b)

- [ ] Two tracks playing: the meters in the headers move with the sound; muting one (M, or Alt+M) silences it and its meter
- [ ] Solo (S, or Alt+S) plays just that track and its reverb return; Ctrl+click solo adds a second track; Ctrl+Z never undoes a solo
- [ ] Volume and pan bars (make a track taller to see them) feel like the modules' bars: drag, Shift for fine, double-click resets, type "-6"
- [ ] Ctrl+Alt+T adds "A Return"; put a module on it; a track's send in the inspector (with Pre on or off) feeds it; the reverb follows the track's volume only when Pre is off
- [ ] The master row selects the master: its chain takes the Limiter; its volume turns the whole mix down
- [ ] Ctrl+Alt+R hides and shows the returns and the master
- [ ] A mix exported or rendered sounds like playback (the master is no longer 3 dB down)

## Mixer view (C3c)

- [ ] "Mix" in the transport bar (or Ctrl+Alt+X) shows every channel as a strip; "Arrange" goes back to the arrangement where it was
- [ ] Faders feel right: 0 dB sits at a comfortable height, Shift is fine, double-click returns to 0 dB, the value under the fader takes a typed "-6"
- [ ] The meters move with the sound; the peak readout holds the loudest peak and resets on a click; it turns red above 0 dBFS
- [ ] Clicking a strip selects the track (the modules below follow); clicking a module name opens that module below
- [ ] Modules, Sends and Narrow change every strip at once; with 30+ tracks, Narrow and horizontal scrolling keep it usable; the master stays in view
- [ ] The header reads as a panel header (MIXER, like INSPECTOR), and Modules, Sends and Narrow read as view options, not buttons: on or off is clear at a glance (a filled dot or a ring)
- [ ] The view and its options come back after saving and reopening the project

## Selection and context panels (A5)

- [ ] Select a MIDI clip, then click another track's header: the clip is deselected, the modules below show that track, and the inspector shows that track only
- [ ] Do the same with a return and the master row: both panels follow at once
- [ ] The inspector reads clearly: CLIP, TRACK, MIX and SENDS each under a small title with a line between them; nothing in it is ambiguous about what it belongs to
- [ ] With several clips selected, the inspector says how many and shows the selected track below
- [ ] Switch to Mix with a MIDI clip selected: the bottom panel shows that track's modules under a plain "Modules" title (no Clip tab, no piano roll), and there is no inspector
- [ ] In Mix, click a module name on one strip, then click other strips and use Left / Right: the modules below follow every time
- [ ] In Mix, Tab, Delete on clips, Ctrl+E, Ctrl+Shift+M and the zoom keys do nothing; the inspector button is greyed; Delete still removes a module you clicked in the chain
- [ ] Back in Arrange, the clip view and the inspector are as you left them
- [ ] Overall: wherever you click, the highlighted track and what the panels show never disagree

## Automation (C4)

- [ ] Right-click the empty space below the tracks: Add track, Add automation lane and Add return track each add one (with their shortcuts shown); the same menu ends every row header's menu
- [ ] Ctrl+Shift+L: an empty lane appears at the end of the tracks with its own colour, "Automation lane", "Not assigned", selected; the lane says how to assign a parameter while it's selected, and goes quiet when another row is
- [ ] With it selected, "Assign parameter…" in the inspector: type "cut", Enter; the lane is named "Cutoff" and says "Bass · Synth" and the value on the right
- [ ] In the inspector's ASSIGNMENTS, "Assign parameter…": switch the picker's channel to another track and pick its Volume. Both parameters follow the lane while playing; set the volume's range from 0 dB to −12 dB, and invert the cutoff's (to below from): both follow as set
- [ ] Assign a parameter that's already on another lane: it moves here (the picker marks it "on <lane>")
- [ ] A lane header's right-click: Rename… puts the cursor in the inspector's name field (Enter renames, Escape doesn't); clearing the name names it after its parameters again
- [ ] In the inspector, clicking an assignment's name shows its module below, even on another track
- [ ] Double-click in a lane adds a point; drag it (it snaps; Alt is free, Shift fine); drag the line between two points up and down; Alt+drag it to bend it; Alt+double-click a point straightens its segment; Ctrl+drag draws; each is one Ctrl+Z, and the controls follow
- [ ] Box-select points, Delete them; Ctrl+D duplicates the selection after itself; arrows nudge them (↑/↓ value, ←/→ a grid step)
- [ ] A filter cutoff drawn as a straight line sweeps like turning the knob evenly
- [ ] The lane's gradient, line and points look like one family with the rest; clicking a lane shows its first parameter's module below
- [ ] A lane whose one parameter is a switch or a choice says "· Steps" and edits as steps; Alt+dragging it explains why it doesn't bend
- [ ] Drag a row's bottom edge to make it taller (Alt: all lanes); at 80 px a one-parameter lane shows the parameter's bar; heights come back after reopening; Ctrl+Alt+L hides and shows every lane
- [ ] Automated knobs, bars, faders and switches show a small dot (filled); right-click: Show automation lane, Remove from automation lane, Assign to automation lane ▸, Automate in a new lane, Reset to default all do what they say (Show from the mixer view too)
- [ ] Moving an automated control by hand turns only its assignment off (its dot becomes a ring; the lane's other parameter keeps playing; the transport's "turn back on" button lights); that button, Ctrl+Alt+A, or the lane's switch turns it back on
- [ ] Automation arm (Ctrl+Shift+A), play, and move a control that's on a shared lane, then one that's on none: the first writes into its lane (the other parameter follows), the second gets a new lane; Ctrl+Z takes the whole pass back at once
- [ ] A project saved before today's lanes opens with one lane per automated parameter, sounding the same
- [ ] A double-click reset on a module's knob is one undo step

## Recording (C5a)

- [ ] Choose a track's audio input in the inspector's INPUT section (or the mixer strip's input row), arm it with its dot (it fills red), and play into it: Auto monitoring lets you hear it through the track's modules; Off silences it
- [ ] Ctrl+R (or F9, or the transport's Record): it records from the playhead; the clip grows in red with its waveform; Space stops; the new clip is selected and named after the track, and Ctrl+Z takes the pass back in one step
- [ ] With an instrument track selected (its dot is a ring: armed by the selection), Record and play the computer keyboard: a MIDI clip with your notes
- [ ] Arm two tracks (click one, Ctrl+click the other) with different inputs and record: each gets its own clip
- [ ] Count-in (its button beside the metronome, or Ctrl+Alt+C; right-click for the length): the metronome clicks a bar first and the position counts down
- [ ] With looping on, start a bar before the brace and record: you hear the lead-in, but only the brace records, a take per lap
- [ ] A track set to MIDI channel 2 ignores a keyboard on channel 1
- [ ] Save a new project: it makes a folder named after it, with the recordings in `Recordings`; move the folder elsewhere and open it: the recordings play
- [ ] Recordings made before saving move into the project's folder when it's saved

## Takes and Capture MIDI (C5b, revised)

- [ ] Record one pass: a plain clip, with nothing about takes on it
- [ ] Loop two bars and record three laps and a bit: the clip shows "3/4 ▾" and its takes open under it (the track grows); it plays the third lap (the last complete one), in full colour on its strip, the others dimmed; the short fourth lap ends where you stopped
- [ ] Click a take's strip: the clip plays it (Ctrl+Z puts the other back); select the clip and press Alt+↓ / Alt+↑ while playing: the takes take turns, the short lap skipped
- [ ] A click on the badge hides the takes (the track shrinks back) and shows them again; a right-click opens its menu: Rename take…, Copy / Move take to new track (a track with the same modules and mix), Spread takes to new tracks, Delete take, Keep only this take
- [ ] Move the clip, to another time and to another track: its takes come with it; trim it and trim it back: nothing is lost; split it: both halves keep their takes; duplicate and delete it: its takes go along (Ctrl+Z brings them back)
- [ ] Record over an imported clip: the recording is a clip of its own, the imported clip cut where it starts, and what it covered is the new clip's "Before take N"
- [ ] Record a take, then a short pass inside it: a new clip, with the take split around it; its badge's menu has "Before take N" (what was there) and the new take. Record a longer pass over all of it: one clip with every take. In its menu, click the takes in any order: each plays alone, the same each time (where a take has no audio, the clip is silent and shows only what plays)
- [ ] Loop-record over a looped clip's brace again: the new laps join its takes, with no "Before take"
- [ ] Place a clip over the middle of a clip with takes, then choose another take on the left part: the placed clip stays; trim the left part back out over it: the takes come back
- [ ] Choose another take on a clip with fades: its fades stay
- [ ] Select a clip with takes, and one playing two parts: they turn lighter like any selected clip, crossfades included
- [ ] Play the computer keyboard, pause 30 s, play a phrase, select a track without an instrument and press Capture (Ctrl+Shift+R): just the phrase lands on it, and no instrument is added; its tooltip named that track first
- [ ] With nothing selected, Capture makes a new track; with an armed MIDI track, it goes there; while playing, it lands where you played
- [ ] With MIDI loop recording set to "Each lap: add to the clip", loop-record MIDI: the laps merge into one clip and make no takes

## Comping (C5c)

- [ ] Open a comp's takes: what the clip plays shows on each strip in the clip's colour, outlined, and the rest is neutral grey; the names of takes in use are bright. It reads at a glance, at the compact width too
- [ ] Loop-record three laps and open the takes. Drag across a strip: while dragging, the stretch shows on it in full colour, outlined; on release the clip plays that take there ("Comp ▾", a line in the body at each change), the strips show what's in use, and the joins sound smooth (10 ms crossfades)
- [ ] Ctrl+Z takes back one swipe at a time; swiping a take back over itself leaves no lines
- [ ] Swipes snap to the grid, and Alt+drag is free; a swipe past the clip's range, or where the take has no audio, changes only what it can
- [ ] Make two comp joins close together and drag their crossfades long: they stop where they meet, never cross; from either side of the spot where they meet, a drag moves that crossfade
- [ ] In a comp's body, drag the line between two takes: a white line shows where it's going; on release the take on the side it left plays up to there (Ctrl+Z puts it back)
- [ ] In a comp, a click on a strip uses that take for the section under the pointer only (the stretch between the lines); the other sections stay. On a clip that isn't a comp, a click plays the whole take
- [ ] Alt+↓ / Alt+↑ while playing step the take of the section at the playhead; the take menu's "Use for the whole clip" items play one take alone
- [ ] Ctrl+click two strips: both outlined, the inspector says "Takes · Selected 2"; the take menu offers Copy / Move 2 takes to new tracks and Delete 2 takes; Delete deletes both (one Ctrl+Z)
- [ ] A comp moves, splits, fades, bounces and exports like any clip, and its own fades stay through swipes

## Top bar and automation (C5b review)

- [ ] The top bar uses its width: tempo, signature, metronome and count-in on the left; the transport and the position centred on the window; status, views and app on the right. At a narrow window the time and the CPU load go first, and nothing overlaps
- [ ] Automation arm (beside Record) lights red; there is no "Turn automation back on" button: move an automated control, then turn its lane back on with the lane's switch; Ctrl+Alt+A (or the palette) turns every one back on
- [ ] Follow (beside Loop) and Count-in (beside the metronome) toggle, and show their shortcuts in their tooltips

## Bounce (C7; signed off 2026-10-10)

- [ ] A Synth part on a track with effects after it (an EQ, a Compressor): select the clip, Ctrl+B. It becomes an audio clip in the same place, same name and colour, selected, a little longer where the release rings on; it sounds exactly the same, and the effects still respond to their knobs
- [ ] Its badge reads "2/2": open its takes; "Before bounce" brings the MIDI back (and the synth plays it again), "Bounce" the audio; each is one Ctrl+Z
- [ ] Bounce a clip followed closely by another MIDI clip: the bounce stops where the next clip starts without a click, and a toast says the tail was cut; select both and bounce: no toast, and the join is seamless
- [ ] Ctrl+B on a MIDI clip of a track without an instrument, or with an EQ before its instrument: nothing happens but a toast saying why; the clip's menu shows Bounce in place dimmed
- [ ] Bounce a long part (a minute or more) while playing: playback never stops; a thin progress line runs along the clip's bottom; Escape cancels it and nothing changes
- [ ] Edit the clip while it's bouncing (move a note): the bounce is dropped with a toast, and the clip keeps the edit
- [ ] Ctrl+Shift+B: a new track right below, named "<track> bounce", in its colour, no modules, the same volume, pan and sends; the original clips dim with "M"; the mix sounds the same; a lane on the source's volume moves the new track's volume too
- [ ] 0 mutes the selected clips (dimmed, "M" before the name) and 0 again unmutes them; the inspector's CLIP Mute toggle does the same; muting survives saving and reopening
- [ ] Right-click a clip: Bounce in place, Bounce to new track, Mute clips, Split, Duplicate, Delete, each with its shortcut
- [ ] Bounce in an unsaved project, then Save As: the files move into the project's `Bounces` folder and the clips still play
- [ ] Ask an assistant to bounce a clip and check it (`bounce_clips`, and `render` before and after: the same measurements): one Ctrl+Z, "Assistant: bounce clips"

## Fades (C6)

- [ ] Split a recording mid-note and play across the split: nothing clicks, nothing dips. Pull the two halves apart: both cut edges fade (zoom in: a 4 ms fade on each), and still nothing clicks; Ctrl+Alt+Shift+E (Edge fades off) makes the cuts click, and on again quiets them
- [ ] A file's own start (a drum sample) keeps its attack: no edge fade there
- [ ] Hover an audio clip: squares at its top corners; drag one inward to make a fade, its dot (or Alt + drag) to bend it; the waveform, the shading and the curve follow the drag, a tag by the pointer says the length or bend, and it sounds as drawn; each gesture is one Ctrl+Z
- [ ] Double-click a fade's square: the fade goes; double-click its dot: it straightens; right-click a fade: Straighten, Remove
- [ ] Two takes edge to edge (or a clip split and the halves from two recordings): drag the first's fade-out square past the join: a crossfade, centred, that sounds smooth, its length in a tag by the pointer; drag its ends to resize it
- [ ] Across the crossfade the waveform is what plays: both clips summed (zoom in on a long crossfade between two copies of one recording: equal power bulges, equal gain doesn't); it stays put while you drag the crossfade's ends (no blinking), and turns lighter with its clip when selected
- [ ] Right-click the crossfade: Equal power (different material), Equal gain (the same material), S-curve; Before, Centred on, After the join (dimmed where there's no spare audio for it); Remove; select both clips and Ctrl+Shift+X: a 10 ms crossfade
- [ ] Split a recording into several pieces, crossfade one join, and zoom out and in: every clip is its own tile, a thin dark seam at each join through the title and the body, through crossfades too; a clip playing two takes has one title and only a line in its body; each fade square sits in its own clip's corner (inside the outline when selected), and a crossfade too short for two squares shows one
- [ ] Two whole files edge to edge: Ctrl+Shift+X says there's no audio beyond their edges
- [ ] Move one clip of a crossfade away and back: the crossfade is gone, not waiting to come back; Ctrl+Z brings it back
- [ ] The inspector's CLIP shows an audio clip's Fade in and Fade out; dragging or typing one sets it
- [ ] Bounce or render a passage with fades and crossfades: they sound as in playback

## Popovers

- [ ] Ctrl+K (palette), Ctrl+Alt+Shift+L on a selected lane (the parameter picker) and the Assistants popover each close on a click anywhere outside them, and on Escape; a menu opened from the picker's channel row doesn't close it

## Sidechain (A2)

- [ ] In the DAW, a Compressor on a bass with Sidechain set to the kick track ducks the bass on every kick; muting the kick track keeps the ducking (a "ghost" kick)
- [ ] The picker lists the other tracks by name and follows renames; a track that already listens to this one isn't offered
- [ ] Changing the source while playing restarts playback briefly and stays in time; Ctrl+Z puts the old source back
- [ ] A Gate keyed from a hi-hat track opens a pad in rhythm
- [ ] Plugins (Reaper, Bitwig, Ardour): route a track to the plugin's sidechain input and set the picker to External: it ducks; on Off it ignores the input; with External and nothing routed it behaves as without a sidechain (VST3); the choice survives saving the host project
- [ ] Ask the assistant to sidechain the bass compressor to the kick: it uses `set_module_sidechain`, and the picker shows the kick

## Assistants over MCP (C9)

- [ ] The spark button in the transport bar opens the Assistants popover; Escape or a click elsewhere closes it; it fits the shell's look
- [ ] Turning it on shows "Listening on 127.0.0.1:7377"; it's still on after restarting the DAW; off, nothing listens
- [ ] Claude Code: paste the copied `claude mcp add` line in a terminal; `/mcp` in Claude Code lists segno with its tools
- [ ] Claude Desktop (or another app that starts a process): the copied configuration works with the DAW running, and also with it closed (it then runs without a window and stops when the app does)
- [ ] Ask the assistant to build a short loop (a drum pattern, a bassline, a filter setting on the Synth): the tracks, clips and notes appear as it works, the light by the spark blinks, and it sounds right
- [ ] Every change it made is one Ctrl+Z, and the palette's undo says "Assistant: …"
- [ ] Ask it to render and check the loop: the numbers it reports make sense (peak, RMS, bands), and playback wasn't interrupted
- [ ] Ask it to collapse a section or fold a module: the panel follows at once, and it never appears in undo
- [ ] Read only: it can still read and render, but every edit is refused with a clear message
- [ ] With unsaved changes, ask it to start a new project: you're asked first (in the assistant's app, or by the assistant), and nothing is lost if you say no
- [ ] New token: the connected assistant stops working until the new line is pasted
